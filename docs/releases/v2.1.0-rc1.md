> 🧪 **Release candidate.** This build is published on the new `beta` Sparkle channel. Stable users won't see it unless they flip **Mindle → Include Pre-release Updates** in the App menu.

## What's new

### Opt-in beta channel for release candidates

Mindle's auto-updater grew a second channel. Pre-release tags (`v2.1.0-rc1`, future RCs) are delivered only to users who've opted in. Stable releases remain visible to everyone.

- New menu item: **Mindle → Include Pre-release Updates** (next to *Check for Updates…*).
- Built on Sparkle's `<sparkle:channel>` mechanism — beta items are tagged in the appcast; the app's `SPUUpdaterDelegate.allowedChannels(for:)` returns `["beta"]` when the toggle is on.
- A custom semver comparator ensures `2.1.0-rc1 < 2.1.0`, so when the final 2.1.0 ships, beta testers correctly upgrade to it.

### Fixes

- **Highlights now appear reliably on every selection.** ⌘⇧H and ⌘⇧N previously read selection state from a 150ms-debounced cache, so a fast select-then-hotkey would either beep silently or anchor the annotation to the *previous* selection — leaving the highlight mark invisible. The hotkey path now probes the live selection from JS at activation time. As a side fix, prefix/suffix anchoring now derives from the selection's actual position in the document rather than the first `indexOf` occurrence, so highlights on repeated text land where you actually selected.
