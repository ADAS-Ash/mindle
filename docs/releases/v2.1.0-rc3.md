> 🧪 **Release candidate.** Auto-update target for users on rc1/rc2 with **Mindle → Include Pre-release Updates** enabled.

## What's new

### About panel shows the full pre-release version

Mindle's About panel used to drop the `-rc2` suffix from the version label, so beta testers on `2.1.0-rc2` saw `2.1.0` and couldn't tell which build they were actually running. AppKit's standard About panel pulls `CFBundleShortVersionString` through Apple's strict `N.N.N` parser, which strips anything after the third integer. We now hand the panel the literal bundle version via `.applicationVersion`, bypassing that normalisation — the pre-release tag is visible.
