## What's new

### Reactions on annotations and replies

A quick "got it" or "agreed" no longer needs a full reply. Each annotation card and thread message row now carries a small reaction picker (the smiling-face icon) with three options: 👍, ❤️, 😄. Tap one to react; tap an existing chip to remove your reaction. The chip shows `glyph count`; hover (or tap-and-hold) reveals the list of reactors by alias.

Reactions live in the same `.mindle.json` sidecar as everything else and flow through the v2.1 sidecar watcher, so a teammate's reaction lands on your screen live without close-and-reopen. Solo-doc users (no identity set) see other people's reactions but the picker stays hidden until identity is configured — same gating as Resolve / Assign.

`get_annotations` over MCP surfaces reactions in both the structured payload (per annotation and per thread message) and the agent-facing text render — so an agent reading the file sees `Reactions: +1 2 (alice, bob), heart 1 (charlie)` next to each annotation. **No write tool in this RC** — agents can read reactions but can't add their own yet. The `react_to_annotation` MCP tool will land in rc2 once the human side has been through a few days of real use.

Sidecar schema is additive: older builds decode v2.2 sidecars without errors (reactions field is optional), and `kind` is intentionally a String (not an enum) so future kinds — emoji picker, custom reactions — decode cleanly on this build too.
