**Mindle 2.2.4** — annotation-card action-row polish. No new features.

## What's fixed

### Reaction picker and label menu icons are actually visible

The smiling-face reaction picker and the tag label menu were near-invisible on the sepia and light themes — their outline SF Symbols at 10–11pt in `c.muted` lost density against the surface, and SwiftUI's `.borderlessButton` menu style was applying a secondary opacity on top of any in-label foreground style, dimming both icons one more step. Easy to miss the picker entirely — most users only found the label menu by cycling themes and noticing the icon flicker into legibility on dark.

Three coordinated changes:

- **`.fill` SF Symbol variants** (`face.smiling.fill`, `tag.fill`) so the glyphs read as solid silhouettes rather than thin strokes.
- **11pt across the row** — both menus now match the trash button's font size at the top-right of the card.
- **`.tint(c.muted)` on each Menu** — defeats `borderlessButton`'s secondary-opacity dimming so the muted color we asked for is the muted color we get.

### Reaction picker no longer floats on its own row

The picker was rendered on a dedicated `HStack` beneath the note editor, even on annotations with no reactions yet. Visually weightless and contextually orphaned: a single tiny chip on an otherwise empty row. Move it inline with the **Assign** and tag menus in the action row up top — same visual group as the other "what would you like to attach to this annotation" affordances. The standalone row now only renders when there are reactions to display.
