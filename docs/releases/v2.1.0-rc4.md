> 🧪 **Release candidate.** Auto-update target for users with **Mindle → Include Pre-release Updates** enabled.

## What's new

### Collapsible YAML frontmatter

Frontmatter blocks (`---`-delimited YAML at the top of a file) used to demand attention as a code-fenced block before the actual content. They now collapse behind a small **▸ YAML FRONTMATTER** chevron and stay out of the way by default — click to inspect. PDF export force-opens any collapsed `<details>` so the printed document still contains the metadata in full.

### Open URL…

New **File → Open URL…** menu item with `⌘⇧L`. Paste an `http(s)` URL pointing at raw Markdown (e.g. a GitHub raw link) and Mindle fetches it, opens it as a tab, and renders it like any local document — search, font scaling, theme cycling, all work the same. The URL becomes the tab's identifier, so re-opening the same URL returns to the existing tab instead of refetching.

Annotations on URL documents **persist** to `~/Library/Application Support/Mindle/url-sidecars/<key>.mindle.json`, keyed by a stable hash of the URL string. Highlight a passage on a remote `README.md` once, close the tab, re-open the URL later — your annotations come back.

If the clipboard contains a URL when you open the prompt, it's auto-filled.
