**Mindle 2.2.0** is the collab-polish + typography release. The v2.1 surface — multi-author annotations with identity, status, threads — gets four user-facing additions that came directly from real-use feedback: reactions (so a quick "got it" doesn't need a full reply), open-from-clipboard (for Markdown sources behind a login Mindle can't see through), reading-width control (so the column actually uses your monitor), and a pair of reading aids (OpenDyslexic font + Bionic Text rendering) for users who want them.

If you've been on the `2.2.0-rc*` train, this is the same code as `rc4`. If you're upgrading from `2.1`, everything below is new.

> 💚 Thanks to [**@ad-cqc**](https://github.com/ad-cqc) for filing the reading-width request ([#27](https://github.com/nonatofabio/mindle/issues/27)) that became the column control, and for [PR #30](https://github.com/nonatofabio/mindle/pull/30) that fixes selectable text inside annotation cards — a careful diagnosis of a SwiftUI re-render quirk that I would have shipped a half-fix for.

## Reactions on annotations and replies

A quick "got it" or "agreed" no longer needs a full reply. Each annotation card and thread message row now carries a small reaction picker (the smiling-face icon) with three options: 👍, ❤️, 😄. Tap one to react; tap an existing chip to remove your reaction. The chip shows `glyph count`; hover (or tap-and-hold) reveals the list of reactors by alias.

Reactions live in the same `.mindle.json` sidecar as everything else and flow through the v2.1 sidecar watcher, so a teammate's reaction lands on your screen live without close-and-reopen. Solo-doc users (no identity set) see other people's reactions but the picker stays hidden until identity is configured — same gating as Resolve / Assign.

Agents can react too. New MCP tool:

```
react_to_annotation(path, id, kind, message_id?)
```

`kind` is `+1` / `heart` / `laugh`; calling twice with the same kind toggles it off. With `message_id`, the reaction attaches to a thread message instead of the parent annotation. The tool description guides agents to reach for this when a written reply would be overkill — acknowledging the user's note, agreeing with a thread message, or signaling "got it, continuing" without taking up a full reply card. Reactions appear in `get_annotations` output too, so the agent sees `Reactions: +1 2 (alice, bob), heart 1 (charlie)` next to each annotation it reads.

## Open from Clipboard

Mindle's `Open URL…` uses an unauthenticated `URLSession`, which means any link behind a sign-in (internal GitLab raw, Confluence with the markdown plugin, vendor doc sites you're SAML-SSO'd into) doesn't render — Mindle can't see what your browser sees. Rather than reinvent the browser, **File → Open from Clipboard** (`⌘⇧V`) lets you carry the bytes across by hand: copy the raw Markdown from the source where you're already authed, paste it here.

The pasted document opens as a tab keyed `clipboard:///<contentHash>` and persists annotations to a local content-addressed sidecar in `~/Library/Application Support/Mindle/clipboard-sidecars/`. Re-pasting the **identical** text — same trimming, same content — activates the existing tab with its prior annotations attached. Different content produces a fresh tab; the original keeps its history.

Tab titles render as `Clipboard · <hash-prefix>` so the strip stays scannable. The v2.1 sidecar watcher still applies, so two open Mindle windows pasting the same content sync each other's annotations through the same plumbing as shared-folder collab. Agents (`list_open_files`) only see real on-disk paths — content-addressed pseudo-URLs are filtered out because there's no path an agent could refer back to.

Auth-walled SPAs and JS-rendered pages still aren't a fit for this approach — those need the WKWebView-backed fetcher with persistent cookies, which is on the v2.3 list.

## Reading Width control

Closes [#27](https://github.com/nonatofabio/mindle/issues/27). The reader pane has always been a fixed 680px column — typography-recommended for line length, but it left big displays mostly blank. New under **View → Reading Width**:

- **Narrow** — 680px (the v2.1 default).
- **Medium** — 920px.
- **Wide** — 1240px.

Direct shortcuts `⌘1` / `⌘2` / `⌘3`. The choice persists per-document in the sidecar (older sidecars decode cleanly without a width field — they get Narrow as before).

## OpenDyslexic font

Bundled, offline, no telemetry. [OpenDyslexic](https://opendyslexic.org/) is a free typeface designed to reduce letter-swap confusions; under **View → Reader Font** you can switch the reader pane between the default serif stack and OpenDyslexic. Code blocks intentionally stay monospace either way — OpenDyslexic isn't fixed-width, and code mis-aligns inside it.

Bundled under SIL OFL with attribution in `Resources/web/vendor/opendyslexic/LICENSE.txt`. Choice persists per-document.

## Bionic Text rendering

Closes [#28](https://github.com/nonatofabio/mindle/issues/28). Toggle under **View → Enable Bionic Text** wraps the first ~half of every word in `<strong>` so the eye has more anchors when scanning long prose. Skips code blocks, headings, and runs that are already bold (no double-bolding).

Composes with whatever font and theme are active — works in OpenDyslexic + Wide + Dark, and any other combination.

## Selectable text in annotation cards

Closes [#29](https://github.com/nonatofabio/mindle/issues/29). [PR #30](https://github.com/nonatofabio/mindle/pull/30) by [@ad-cqc](https://github.com/ad-cqc). Text inside an annotation card or thread message was previously unselectable: SwiftUI's `Text(...).textSelection(.enabled)` doesn't survive the sidebar's per-mutation re-render (every store change rebuilds every card via `ForEach`, dropping the in-flight drag selection — the same root cause that drove `FocusStableTextEditor`). The fix replaces those `Text` views with a new `SelectableText` `NSViewRepresentable` that owns its `NSTextView` across SwiftUI rebuilds and computes a wrap-aware `intrinsicContentSize` for self-sizing layout. ⌘C now copies; drag-select holds even when a sibling agent reply arrives mid-drag.
