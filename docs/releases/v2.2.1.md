**Mindle 2.2.1** — single-fix polish patch on top of v2.2.0.

## What's fixed

### Reading width and font choices now stick across documents

In v2.2.0, **Reading Width** and **Reader Font** were stored only per-document in the sidecar. Picking Wide + OpenDyslexic on one file would not carry over when you opened the next — every fresh file reverted to Narrow + Serif until you re-set the menu each time. Annoying, especially on a wide display where Narrow leaves dead space on every doc.

Both preferences are now also persisted in `UserDefaults` as your user-level default. Picking a width or font from the menu records the choice; the next document you open inherits it. Per-document overrides still work for anyone who wants a specific doc to keep its own setting — if a sidecar carries an explicit `readingWidth` / `readingFont` field, that wins for that file. Existing v2.2.0 sidecars decode cleanly with no migration.
