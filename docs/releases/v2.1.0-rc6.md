> 🧪 **Release candidate.** Beta-channel update on top of rc5. Two collab polish fixes from real-use testing.

## What's new

### Collab row appears on the first save, not after a reload

`writeSidecar`'s auto-register-current-user logic was operating on a local copy of the collaborator map and writing it to disk, but never mirroring the change into the `@Published` `collaborators` state. Result: on a fresh document, you'd set your identity, create a highlight, and the **Resolve / Assign / Labels** row would stay hidden until you closed and reopened the file — at which point `loadSidecar` finally pulled the now-persisted registry back into memory. The mirror is now in place; the row appears on the same tick the save commits.

### Sidebar shows author colors and truncated aliases

The reader pane already picked up collaborator colors from the registry, but the *sidebar* cues (annotation card dot, the passage's left stripe, the thread message stripe) still used the old "agent vs. not-agent" theme tokens. On a multi-author doc, both your annotations and a teammate's looked identical inside the sidebar — only the reader-pane highlight distinguished them. Now the sidebar consults the same registry:

- **Card header** carries a `· <alias>` label in the author's color, truncated to 8 chars when long. Agents skip it (the AGENT type-label already identifies them); pre-identity `"user"`-stamped annotations stay clean.
- **Card dot + passage stripe** use the author's registered color.
- **Thread rows** show a per-message author label (in the stripe color) above the timestamp, so you can scan a long thread for "who said what" without tracking the left stripe across the row.
