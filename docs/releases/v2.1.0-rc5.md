> 🧪 **Release candidate.** Auto-update target for users with **Mindle → Include Pre-release Updates** enabled. The headline addition is team collaboration on top of the existing annotation system — please put it through its paces.

## What's new

### Team collaboration on annotations

Annotations gain four optional dimensions, all stored in the existing `.mindle.json` sidecar so old files decode unchanged:

- **Status** — open / resolved / wontfix. Each annotation card shows a status pill and a Resolve / Reopen button.
- **Assignee** — pick from the collaborators registered on the document.
- **Labels** — presets (`question`, `blocker`, `nit`, `todo`, `suggestion`) shown as pills on the card.
- **Collaborator registry** — alias → display name + color + type (human / agent), auto-registered on every save.

The annotations sidebar grows a small identity badge at the top (click to set your alias) and a `+` button to add a note on the current selection. New keyboard shortcut: `⌘⇧K` for *Add Comment to Selection*.

### Identity-colored highlights

Each annotation now carries its author. The reader pane tints the highlight with the author's color from the registry — your highlights in your color, a teammate's in theirs — via a CSS custom property + `color-mix` so the tint reads against light, sepia, and dark themes alike. Annotations with a note keep the color but bump the tint slightly so the note distinction comes through the underline.

### Agent-facing MCP tools

Three new tools route through `DocumentStore` so the live app updates alongside the disk write:

| Tool | Use |
|---|---|
| `resolve_annotation(path, id, author?)` | Mark a thread resolved. |
| `assign_annotation(path, id, assignee)` | Hand an annotation to a collaborator. |
| `get_collaborators(path)` | List participants on a document. |

### Other

- **Debug console** (`⌘⇧D`) — floating dev window streaming annotation lifecycle events. Handy when iterating on the collab UI.
- A handful of post-merge polish bits: corrected indentation in the collab row, scoped the `has-note` CSS rule so it no longer flattens the author color on noted annotations, dropped a stray orphan doc comment.
