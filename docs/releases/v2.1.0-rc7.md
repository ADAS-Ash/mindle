> 🧪 **Release candidate.** Final RC before v2.1.0. Three multi-author cleanups on top of rc6 (issues #18, #19, #20).

## What's new

### MCP path lookups survive symlinked roots

`list_open_files` reports a document's path via Foundation's standardize, which canonicalises trailing components — so a file opened from `/tmp/foo.md` came back as `/private/tmp/foo.md` on macOS. The open-tab store still keyed off the raw URL the user opened, so `get_annotations` on that same returned string was rejected as "file not open". Same hazard on every MCP path-keyed entry point (replies, agent annotations, clears, resolve / assign / collaborators). `URL.canonicalPath` (`resolvingSymlinksInPath().path`) now normalises both the incoming `path` argument and the stored `tab.fileURL` at every match site. `/tmp` and `/private/tmp` collapse to the same key; same for any other mid-path symlinks (e.g. `/var` → `/private/var`).

### Each tab carries its own collaborator registry

Before: the collaborator registry was a single window-scoped state shared across every open tab. Switching from doc A (sam → red) to doc B (alex → blue) meant doc B's annotation cards lit up with sam's red dot until you re-loaded — and a subsequent save on doc B would happily mirror doc A's collaborators into doc B's sidecar, polluting the file. Now each `DocumentTab` carries its own collaborator snapshot, captured on switch-out and restored on switch-in. Fresh tabs reset the registry before `loadSidecar`, so a doc with no sidecar can't inherit the previous doc's authors.

### External sidecar edits flow in while the file is open

Annotations live in `.foo.md.mindle.json` next to the doc. Until now the only writer Mindle expected was itself, so the watcher only ran on the markdown body — any external edit to the sidecar (another Mindle instance writing through a shared folder, a `git pull` on a shared repo, a teammate's collab tool, a hand-edit) was silently ignored until close + reopen. Each open tab now gets a sibling watcher on the sidecar; foreign writes get pulled in via `loadSidecar()` and snapshotted into the active tab. Self-writes are suppressed by a 750ms timestamp guard around `writeSidecar` so the FSEvents echo from our own atomic save doesn't loop.
